# Client Requirements

## Project Overview

This document describes the client requirements for the CMPG325 network design project.

## Network Requirements

The proposed network should provide:

- Reliable network connectivity
- Appropriate IP addressing
- Secure communication between network devices
- Connectivity between required departments and devices
- Internet connectivity where required
- A scalable network design for future expansion

## Performance Requirements

The network should provide reliable communication between connected devices while maintaining efficient use of network resources.

## Security Requirements

Network devices should be configured appropriately to prevent unauthorized access and protect network resources.

## Future Requirements

The network should allow for future expansion and additional network devices.
